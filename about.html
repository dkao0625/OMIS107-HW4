HOW IT WORKS

Information, straight from the source

The server reads public Santa Clara University web pages and extracts event titles, times, places, and library hours. Event search and the evening filter are ordinary word and time filters in your browser—there is no AI involved.

Campus Today checks each source’s robots.txt, identifies itself in its User-Agent, caches fetched pages, and waits at least 30 seconds before requesting the same page again. If a source is unavailable or does not publish readable information, the page says so instead of guessing.
